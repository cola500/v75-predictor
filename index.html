Motiveringen väljs efter vilken faktor som sticker ut mest för hästen, i prioritetsordning:

  1. Karriärvinst ≥ 30 % → "Vinner X % av sina starter"
  2. Form ≥ 30 % → "Het form: X % vinst 2026"
  3. Kuskvinst ≥ 20 % → "Het kusk: X % vinst 2025"
  4. Intjänat ≥ 50 000 kr → "Tjänat X kr 2026"
  5. Innerspår (1–3) vid volte → "Kan rusa ledningen direkt"
  6. Tränaren ≥ 15 % vinst → "Topptränare"
  7. Annars → "Toppscore på sammanvägd statistik"

Marknadens topp-3 är de tre hästar som har lägst vinnar-odds just nu — dvs. de som spelarna tror mest på. När vår topp-3 matchar marknadens får hästen taggen Marknadsfavorit. När vi tycker annorlunda får hästen Avviker från marknaden — spännande men mer risk.

Enkel heuristik — tittar inte på banans karaktär, väderlek, motståndarnas relativa styrka, skobyten eller senaste 3-5 starternas trend. Fungerar som ett dugligt grundval, inte som garanti.
